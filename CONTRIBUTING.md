# Contributing to Fulmar

Thank you for your interest in Fulmar.

## Current status

Fulmar is undergoing private engineering and release qualification. The application source has not yet been published, no open-source licence has been selected, and application-code contributions are not currently being accepted.

You may review and comment on the repository-foundation documentation. Please do not submit copied application code, reverse-engineered binaries, model weights, generated runtimes, credentials, personal data, or third-party material whose redistribution terms are unclear.

## Before contributions open

The project owner must complete and publish:

- the project licence and matching third-party notices;
- the source tree and reproducible build instructions;
- contribution and authorship terms;
- a private security-reporting route;
- required continuous-integration checks;
- formatting, testing, review, and release policies;
- a code of conduct and maintainer decision process.

## Safe public communication

Never include API keys, authentication headers, private prompts, personal filesystem paths, Keychain data, signing certificates, model data, or confidential diagnostics in an issue or pull request.

Bug reports must identify the exact Fulmar version and build, macOS version, hardware class, model/provider route, and reproducible steps without private content. Logs must be reviewed and sanitised before sharing.

## Pull requests

Repository-foundation pull requests should remain small and reviewable. Explain:

1. what changed;
2. why it is appropriate before source publication;
3. what was tested;
4. whether the change alters any public claim, security boundary, licence, or release gate.

Submitting material does not grant Fulmar permission to use it until the eventual contribution and licence terms are published and accepted.
