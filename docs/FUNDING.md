# Funding Fulmar

Fulmar's intended model is a free, MIT-licensed source release with optional community support. Formal source publication remains subject to the project licence, third-party redistribution review, and release qualification.

## Principles

Support is voluntary. Paying must not:

- unlock security updates or essential functionality;
- weaken privacy or introduce advertising or behavioural tracking;
- change the local-versus-cloud data boundary;
- guarantee a requested feature, delivery date, or support response;
- replace the normal security-reporting process.

Fulmar will not sell prompt content, diagnostics, usage data, provider choices, or model activity.

## What support funds

Project support may help cover:

- Apple Developer Program membership, signing, and release preparation;
- disposable provider credits used for qualification;
- hosting, domains, continuous integration, and release storage;
- test hardware and supported-macOS coverage;
- continued engineering, documentation, maintenance, and user support.

## Planned channels

The initial funding channels are expected to be:

- Buy Me a Coffee for simple one-time support;
- GitHub Sponsors for one-time or recurring developer sponsorship.

Payment is handled on the selected provider's website. Fulmar's native app should open a clearly labelled external link in the user's normal browser rather than embedding payment or tracking code.

No funding link will be published until the repository owner has verified the account, payout destination, public wording, and URL.

## Recognition

Supporters may optionally be thanked in project documentation or release notes. Names, organisations, amounts, email addresses, and messages will not be published without explicit permission.

## Financial transparency

Public wording should describe payments as support for development, not charitable donations. Platform fees, taxes, refunds, records, and reporting remain the project owner's responsibility.
