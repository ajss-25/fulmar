# Support

Fulmar has not yet published a supported public release or download.

The repository may be used to follow project preparation, but it is not currently a support channel for privately built or unofficial Fulmar binaries. Do not obtain builds from third parties or follow instructions that bypass macOS security controls.

Before the first supported release, this document will define:

- supported Fulmar versions and macOS releases;
- supported hardware, local runtimes, models, and remote providers;
- installation, update, rollback, and uninstall guidance;
- privacy-preserving diagnostics;
- response expectations and end-of-support policy;
- the private vulnerability-reporting route.

For now, public issues should be limited to non-sensitive repository documentation problems or clearly labelled product suggestions.
